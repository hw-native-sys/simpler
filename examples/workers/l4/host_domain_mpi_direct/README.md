# Host domain Direct MPI acceptance

Validate one or two A3 executors, each owning one Host DRAM window and two HBM windows.
The same runner covers CPU owner accesses, explicit ACL SDMA copies, and active NPU kernels.

See the [Chinese runbook](../../../../docs/zh-cn/host-domain-mpi-validation.md) for complete single-node and two-node commands, prerequisites, checks, and result boundaries.
