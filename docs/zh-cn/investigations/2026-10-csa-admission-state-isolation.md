# CSA 准入状态独占 128B：单独布局改动暂不保留

日期：2026-10-27。
结论：已撤回，恢复 TaskControl 384B；不是宣称严格零收益。

## 问题与试验

admission_state 与 claim_tickets 同处第一个原子区域，可能发生额外争用。
本试验只把前者从 offset40 移到 offset384，独占 128B；TaskControl 从 384B 增至 512B。
其余既有字段 offset、原子次数、三 lane、N≥2P 单块取号、sync_start 和业务均不改变。
CSA 的 107 个控制记录增加 13696B。数组步长和后续区域地址也改变，不能把结果归因于单一 bank。

基线生产 diff 为 e59d3419…，候选为 c93239e1…；三个原生二进制与源码一起切换。
同卡按 B/A/A/B 运行，每批三轮七项 golden、5 次预热及 100 个正式样本。
54 个链接后 kernel 指纹完全相同，竞争 A5 CLI 监测为空；无 task-submit 隔离，不能排除其他干扰。

## 结果与决定

| 批次 | 完整 Device 中位数（us） | Host 中位数（us） |
| ---- | ------------------------ | ----------------- |
| B1 | 2955.6550 | 80478.2475 |
| A1 | 2990.0350 | 144166.9345 |
| A2 | 2963.1440 | 74082.8655 |
| B2 | 2957.5390 | 79004.9165 |

每臂 200 个样本，合并 Device 中位数 A=2975.3975us、B=2956.951us，候选小幅改善 0.62%。
第二对 A2/B2 只差约 5.6us（0.19%），小于两批基线约 26.9us（0.90%）的变化。
A1 Host 明显漂移，不能据 Host 差值声称端到端收益。
没有继续为这个微小差值扩大独立批次验证，现有证据不足以支持将控制记录扩大 33%，因此撤回。

候选通过 C++ 933 项、Python 2838 项、两平台各 645 个边界场景和各七项两波有界故障。
原样 CSA 严格 L4 核验 2308 个执行身份、133 条依赖和 46733 个协议事件。
正确性通过不等于优化值得保留；这轮也没有完成所有旧故障矩阵和最终全 HBG 回归。

## 何时重新评估

若其他负载或更多独立批次能证明稳定、可归因且值得内存开销的收益，再重开本条目。
若为了改变准入阶段的发布域而必须隔离字段，须把所有权和发布语义完整设计、测试，
并把布局本身与发布方式的效果分开；不能用本轮微小差值给另一种协议背书。
下一项更直接的线索是小 N 普通任务仍采用 CAS，实际调用很短而任务跨度仍大。

2026-10-28 补充：后续在普通 N>1 取号的基线上，将短领取锁与阶段发布分离，
阶段使用独立 128B 的 st_dev＋DSB／ld_dev 信号，因此重新采用 TaskControl 512B。
该整体候选的 B/A/A/B 完整 Device 合并中位数为 2.748478→2.413584ms（约 12.18%），
边界、故障及严格 L4 通过后保留，见[阶段发布对照](../../../tests/fdwic/pa_hbg/spmd/perf_data/2026-10-27-csa-poursoul/sub2ms-admission-phase-comparison.json)。
这不是撤回本页的“仅布局不保留”结论；两个实验基线不同，不能相减精确拆分 padding 与发布贡献。
