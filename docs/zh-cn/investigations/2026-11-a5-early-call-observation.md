# A5 不可变执行包的提前观察实验

**2026-11-13：轮转预观察候选已撤回，未建立综合 device L0 收益。**
保留 Host 收尾导出的构造者、执行者及构造时间，作为后续分析证据。

## 尝试与边界

在 `7c1c4a58b` 的私有后台构造游标基础上，每核增加两个可让出的只读
view。空闲分支每轮最多观察一个兼容 node 的首选 block：强确认 BUILT，
对 Call 做定向 DCCI、尾 DSB 和校验。观察不领取执行权，不占执行 slot、
admission 或 async writer；实际 ready claim 成功后才能使用 view。

命中时省去重复接收观察；未命中时让出一个旧 view。没有修改业务 kernel、
输入、MIX 会合、sync_start entry permit 或 defer_wait 的完成语义。
atomic-only 控制行与普通数据仍隔离，继续遵守 atomic_probe 的交权约束。

## 完整十八组 L0

同卡配对，对照为上述私有构造游标版，候选为预观察版。每组每版预热一次、
计时十次，统计完整 `chip.run.runner_run.device_wall`；通信每轮先取两
rank 最大值，再求十轮均值。所有十八组、两臂共三十六项数值校验通过。

| 范围 | 对照均值之和 / ms | 候选均值之和 / ms | 耗时变化 |
| ---- | ----------------- | ----------------- | -------- |
| 十四组非通信 | 19.4511973 | 19.5148694 | +0.3273% |
| 四组通信 | 59.6567885 | 59.0222739 | −1.0636% |

四组通信不计综合验收，但并未免于报告。候选通信汇总仍较原 main 的
26.3232031 ms 高 124.22%，不能将历史回退直接归因于通信噪声。

原始 main `2f61d0c6c` 的十四组汇总为 19.9902648 ms，固定目标仍为
**不高于 11.99415888 ms，即耗时下降至少 40%**。本候选相对该基线只
下降 2.3781%，也未优于同轮对照。上述小幅差异没有证明稳定回退的
精确幅度；保留决策是没有建立综合收益，不引入任意百分比忽略区间。

## L3 证明了什么

单卡 SWA/lib 配对捕获使用相同的 600 ns 函数过滤阈值，各有 631 个
执行身份、96 条 Scalar stream，无丢失或截断。每版预热一次、捕获一次。

- 596/631 个执行单元由其他核构造。
- 607 个有前驱的执行单元中，575 个的构造主体在前驱返回前结束；
  这不是 BUILT 发布时刻的证明。
- 309/607 个执行单元的实际接收观察结束早于前驱返回，证明接收工作
  确实提前。此项不是所有 view 的命中率，也不能计为执行许可。
- t22→t29 的间隙为 21.972→20.381 µs；相同关键链的间隙合计为
  312.474→313.710 µs，kernel 包络为 919.513→955.271 µs。
- t1 启动跨度为 81.478→91.415 µs；t21→t22 的 MIX 交接为
  45.825→48.810 µs。局部少做一次观察没有消除这些等待。

`scalar_payload` 中位数从 3.139 降至 2.591 µs，但次数从 1297 增至
1480；准备、领取、分配尾部仍在关键路径。次数和各核区间之和不能
换算为全设备 wall time 的节省，也不能用 L3 直接预测 L0 收益。

首次 L3 导出失败于 Host 校验器的枚举上界：新增的 `ScalarCallObserve`
被当作非法 interval，导致整个 Scalar stream 扩展未输出。修正 Host
上界后重采取得上述有效数据；AICore/AICPU 二进制不变。首次不完整
捕获不参与分析。该事件及 view 路径随后一起撤回。

## 下一步的证据要求

不通过增加 view 数量或任意扫描预算反复试参。优先定位真实关键核的
MIX admission、组分配和普通 SPMD 未领取 block 的发现路径，解释为何
部分兼容闲核未及时接手，再改变分配机制。

历史[独立 block 调度回退分析](2026-11-a5-hbg-dsv-scheduler-review.md)
已证明逐 block 重走共享队头、payload 和 join 的代价；新的分散方案
必须说明其成本区别，不能只凭移除 ready 队列就宣称更快。当前的
per-cell claim 后仍有共享分配计数，应把它与领取顺序一起审视。

只有改变了工作前移方式或其他串行环节，并由可比泳道图支持时，才
重新考虑提前观察。40% 整体目标和 5 µs 局部目标均未达成。
